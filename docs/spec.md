# 仕様（2026-11-02 版、11/3 に「聞くことを言葉にする」を実装に合わせて直した）

高齢の方や介護する家族が困りごとを書くと、尋ねていない公的制度まで、判定の理由・申請先・持ち物・出典つきで示す相談窓口。国の制度 17 件は全国で判定し、都道府県の制度は東京都の 1 件、市区町村の独自の制度は町田市の 10 件と横浜市の 7 件を詳しく判定する。ほかの市区町村では、市区町村の事業の型 5 件を「お住まいの市区町村にあるか窓口で確かめる候補」として示す。町田市か横浜市に住んでいると分かったときは、型は出さない（市の制度を一つずつ判定しているため。その市で書けていない型は規則の `shown_in` で出す）。その市・都以外と分かったときは、そこの制度は出さない。町田市・横浜市の外の人には「町田市にお住まいなら、市の制度 10 件も判定します」のように 1 行添える。住所が分からない間は、市・都の制度も型も出す。住所の事実（町田市・横浜市・東京都に住んでいるか）は、選んだ市区町村から決め、町田市に住んでいると読み取れたときは東京都に住んでいることも埋める。住所の問いは市区町村を選ぶ欄 1 つで、値打ちは規則が使う市・都ごとに 1 つと「そのほか」で数える。町田市ではないとだけ分かったとき（相談文の読み取りなど）も、横浜市・東京都に住んでいるかが分からなければ、同じ欄を 3 問の枠でもう一度出す。住所の問いに「わからない」と答えたら、住所はもう聞かない。

## 役割の分け方

| 役割 | 担当 | 理由 |
|---|---|---|
| 相談文から事実を取り出す | Claude（tool use） | 話し言葉の「母」「退院した」「独り暮らし」を事実に直すのは言葉の仕事 |
| 制度に当てはまるかを決める | 規則のプログラム | 判定は説明でき、テストでき、同じ入力に同じ答えを返す必要がある |
| 次に何を聞くかを決める | 規則のプログラム | 「答え次第で判定が変わる制度」を数えれば決まる |
| 聞くことを言葉にする | 規則ファイル＋Claude の読み取り | 問いの文と選択肢は `rules/facts.yaml` に固定し、Claude が相談文から読み取った呼び方（お母さま など）を「ご本人」の所に差し込む。問いの文を Claude に毎回書かせないのは、同じ問いに同じ選択肢を出し、費用を読み取りの 1 回に抑えるため |
| 出典・申請先・持ち物 | 規則ファイル | Claude は書き足さない。出典のない制度は出さない |

## 流れ

1. 相談文を受ける。
2. Claude が事実を取り出す。事実ごとに確信（高い／低い）と、相談文の中の根拠の箇所を返す。根拠が相談文に見つからない事実は確信を低いに落とす。要介護・要支援の区分は、相談した人の思い違いで判定が大きく変わるので、文にはっきり書いてあっても確信を低いに落とす（`ALWAYS_CONFIRM`）。
3. 判定器が制度ごとに 6 つの状態のどれかを返す。
   - 当てはまる見込み：聞ける条件をすべて満たす。残りは申請で確かめる（医師の意見・市の審査・所得の書類など）。
   - 先に手続きをすると使える：前提の手続き（要介護認定、町田市の認定書・確認書）を済ませれば対象になりうる。
   - 確かめると使えるかもしれない：判定を決める事実が分からない。確かめ方を添えて出す。
   - 当てはまらない：条件を 1 つ以上満たさない。理由つきで、たたんで出す。
   - 申請済み・結果待ち：申請して結果を待っている（規則の `pending_when`。例：要介護認定を申請中）。これを前提にする制度は「先に手続きをすると使える」のままにし、画面では前提の名前に「申請済み・結果待ち」と添える。
   - 済んでいる：もう済んでいる手続き（規則の `done_when`。例：認定を受けている）。「当てはまらない」と一緒にたたんで出す。
4. 足りない事実のうち、答え次第で状態が変わる制度が多いものから 1 問ずつ聞く（最大 3 問）。答えるたびに数え直す。
   - 3 問で確かめきれなかった確信の低い読み取りは、結果の画面の「まだ確かめていないこと」に、同じ形の問いで並べる。答えると規則だけで判定し直す（問いは足さない）。まとめは、扱う制度が変わったときだけ書き直す。
5. 結果を出す。制度ごとに、どの条件をどの答えで満たしたか、申請先、持ち物、公式ページの URL と確認日。
   - 欄の中は重い制度から並べる。ただし「確かめると使えるかもしれない」は、分からない条件が少ない順、次に当てはまった条件が多い順に並べ、先頭の 5 件だけを開いて出す（あと少し確かめれば決まる制度を先に見せるため）。

## 聞き返しの決まり

- 問いの値打ち＝その事実の答え次第で状態が変わる制度の重みの和（選択肢ごとの平均）。重みは規則ファイルの `weight` に、その制度を前提にする制度の数を足したもの。
- どの答えでも状態が変わらない事実は聞かない。
- 答え方はボタンだけで進める。はい・いいえの問いは「はい／いいえ／わからない」。
- 「わからない」も正式な答え。その制度は外さず「確かめると使えるかもしれない」のまま、確かめ方を添える。同じ事実は 2 度聞かない。
- 確信の低い事実は「〜ですか？」の確認の問いにする。
- ただし認定の区分（`ALWAYS_CONFIRM`）は「〜ですか？」にしない。読んだ値と被保険者証の見る欄を文で示し、区分を全部並べて選んでもらう。「わからない」の代わりに「いま確かめられない（読んだ値として進める）」を出す。
- お住まい（町田市に住んでいるか）は「町田市にお住まいですか？」と聞かず、都道府県と市区町村を選ぶ欄で聞く。町田市以外の人も自分の市区町村を選べ、選んだ所は入口で選んだときと同じに扱う（申請先の書き方と、地域包括支援センターを探すリンクの都道府県が決まる）。
- ボタンを先に選んでおかない。
- 聞き返した数・押した数・かかった秒数を結果の画面に出す。数えるのは画面の側で、相談文と答えはサーバに残さない。

## 規則ファイル

- `rules/facts.yaml`：事実の定義（型・選択肢・問いの元の文・確かめ方）。住所の事実は `place`（市の団体コードか都道府県の番号）を持ち、選んだ市区町村から決まる。`read: false` の事実は Claude に読ませない。
- `rules/programs/*.yaml`：制度ごとに 1 ファイル。条件の木（all／any／not と葉）、申請で確かめる条件、前提の手続き、申請先、持ち物、出典。`level` は national（国）・tokyo（東京都）・machida（町田市）・yokohama（横浜市）・local（市区町村の型）。市区町村の型の `shown_in` は、市の制度を一つずつ判定している市でも型のまま出す市。
- 条件の葉は `fact` と `in`／`eq`／`is` のどれか、理由に出す `label` を持つ。`via` は「この条件は別の制度の手続きで満たせる」、`prereq` は「別の制度の手続きが先に要る」。
- 出典は URL・発行元・利用条件・確認日を持つ。原文の引用は公共データ利用規約（PDL1.0）のページだけ。町田市のページは独自の規約で無断転載が禁じられているので、条件は自分の言葉で書き、リンクを示す。横浜市・東京都福祉局のページも転載不可なので同じにする。東京都福祉局はトップページ以外へのリンクに事前の許諾が要るので、出典にはトップページを示す。
- 国の制度は `procedures` に、デジタル庁の行政手続データの手続（手続ID・手続名・法令名・根拠条項号・添付書類）を持つ。値はデータのまま写し、`tests/fixtures/procedures_r7.json` の控えと照らす。その制度だけの手続がデータにないとき（税の控除）は、使う一般の手続を `match: general` で結び、関係を `note` に書く。使う手続がデータにまったくないとき（事業主への申し出、社会福祉協議会との契約・貸付）は、`procedures_none` に探した日と理由を書く（空にしない）。

## 評価

- 架空事例 30 件。事例ごとに、相談文・人物の説明・聞かれたときの答え（事実）を持つ。事例は規則ファイルを見ずに人物から書く。
- 正解は柴田が人物の説明と公式資料から付ける（事例×制度で「案内すべき／すべきでない」）。判定器の結果は見ずに付ける。
- 比べるもの
  1. 規則だけ（事実をすべて与える）：規則の正しさ。
  2. 窓口全体（相談文 → Claude が取り出す → 最大 3 問を事例の答えで返す → 判定）。
  3. Claude だけ（同じ相談文を Claude に渡し、使える制度を挙げさせる）。
- 測るもの：案内すべき制度を拾えた率、案内すべきでない制度を出した数。聞き返した数ごとの拾えた率。

## 公開

- Fly.io（自動停止）。合言葉と回数制限は手間を増やすだけの対策で、使われすぎは API の専用ワークスペースの上限で止める。合言葉は Claude を呼ぶ口（読み取り・まとめ）だけに掛け、規則だけで動く判定し直しと、前もって読み取った見本 3 件は合言葉なしで使える。
- 鍵はリポジトリの外に置き、環境変数で渡す。

## 扱わないこと

- 体の状態の判断や治療の助言はしない。出すのは制度・申請先・持ち物だけ。
- 公式ページの文章を Claude が要約して答える作りにはしない（判定は規則）。
